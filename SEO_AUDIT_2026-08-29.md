# Hiriq SEO Pass — 29 August 2026

Follow-up to `SEO_AUDIT.md` (23 August 2026). That pass built the commercial
page map. This pass fixes a crawl-level defect, adds the bottom-of-funnel
comparison cluster, and puts the earned press coverage into the site's entity
graph.

## The defect worth reading first

**Site-wide structured data was never in the served HTML.**

`app/layout.tsx` rendered the Organization / WebSite / SoftwareApplication /
Person / SiteNavigationElement graph through `next/script`. With no `strategy`
prop, `next/script` defaults to `afterInteractive`, which injects the tag
*after hydration*. The JSON-LD therefore existed in the DOM but not in the
server-rendered source.

Verified against production before the fix:

```
curl -s https://hiriq.co | grep -c '"@type":"Organization"'   # 0
curl -s https://hiriq.co/solutions/ai-recruiting-software \
  | grep -c 'application/ld+json'                             # 2
```

Solution pages were fine because they used a plain `<script>` tag. The
homepage, and every page relying only on the root layout, shipped no entity
markup at all. That is a direct contributor to weak brand-entity association,
which matters here because "hiriq" is also a Hebrew diacritic with an
established Wikipedia entity competing for the same string.

Fixed by rendering the graph as a plain `<script type="application/ld+json">`
in the root layout. `next/script` is still used for GA and the LinkedIn tag,
which is the correct use for those.

| `/compare/best-ai-recruiting-software-for-staffing-agencies` | AI recruiting software for staffing agencies |

Editorial rules applied to every page, and they should hold for future ones:

- Hiriq appears in each list and is labelled "Our product" in both the table and
  the detail card. No page claims Hiriq ranks first.
- Competitor entries summarise publicly stated positioning only. No invented
  scores, star ratings, quoted pricing, or performance claims.
- Lists are ordered by category, never by rank.
- Every page carries a visible "Last reviewed" date and tells the reader to
  confirm current features and pricing on the vendor's own site.
- Outbound competitor links are `rel="noopener nofollow"`.

The differentiator these pages compete on is the distinction between platforms
that score the candidate, platforms that record the conversation, and platforms
that evaluate the interviewer. That framing is what the category's existing
listicles mostly miss.

## Off-site, and not doable from this repo

These are the actual constraint on brand-term ranking. Ordered by impact.

1. **Google Search Console.** Verify the domain, submit
   `https://hiriq.co/sitemap.xml`, and use URL Inspection on `/`, `/press`,
   `/compare`, and the new pages. Without this there is no visibility into
   whether pages are indexed at all.
2. **Bing Webmaster Tools.** Same, and it feeds ChatGPT search results.
3. **Claim the Org profile** at `https://theorg.com/org/hiriq`. It is currently
   unverified with zero followers. Claiming it strengthens the entity link.
4. **LinkedIn company page** — confirm the website field points to hiriq.co and
   the description matches the Organization schema wording.
5. **Crunchbase, G2, Capterra listings.** These are the directories Google
   leans on for software-entity confirmation, and the category competitors all
   appear in them.
6. **Wikidata item** for Hiriq the company. The single strongest lever against
   the Hebrew-diacritic entity currently owning the query string.

## Do not

- Claim SOC 2, HIPAA, GDPR, or EEOC compliance without documentation.
- Publish testimonials, client logos, case studies, or review scores that do not
  exist.
- Add competitor pricing to comparison pages. It goes stale and it invites
  a complaint.
- Rank Hiriq first in a list Hiriq publishes.
