# Hiriq Portfolio

Next.js marketing site for Hiriq.

## Environment Variables

- `NEXT_PUBLIC_GA_ID`: optional Google Analytics measurement ID.
- `NEXT_PUBLIC_LINKEDIN_PARTNER_ID`: optional LinkedIn Insight Tag partner ID from LinkedIn Campaign Manager.

Copy `.env.example` to `.env.local` for local development and add the same values in the deployment environment.

## Development

```bash
npm install
npm run dev
```

## Production Check

```bash
npm run build
```
